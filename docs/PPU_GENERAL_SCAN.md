# General PPU prefill dispatch

The source tree stays in its HGGC format. Preprocess a separate build worktree with `python3 /root/lfwang/Projects/flytiger/cudafy-for-sail/cudafy.py flashkda <build-worktree>` and commit the converted source before compiling. The production package uses the measured tc02 extension without recompilation.

The C16 path selects temporal parallelism from sequence capacity, head count and the original CTA grid. Cooperative launch requires at least one CTA per CU and is admitted using the runtime's actual resident-block capacity for the selected kernel on the current device. Existing qualified dispatches remain in place; grids with enough ordinary recurrence parallelism retain that recurrence.

Current device sequence boundaries select the serial or parallel work on every call and Graph replay. The general scan partitions complete chunks, builds affine summaries, propagates carries and replays output. Short requests use the original row-split recurrence. Exact in-place state updates are supported; overlapping buffers that could cross sequence dependencies retain serial recurrence.

Prepare uses bounded tile loops sized from the actual resident capacity to reduce empty CTAs for padded requests. General scans fold their prefix and classifier into prepare. Batched native recurrence reuses the original standalone prefix table; single-request H12 prepare publishes its prefix. If compact preparation would require more than one resident wave while the recurrence remains native, dispatch retains the original streaming prepare grid and its original thread geometry. Large FP32 H6 legacy scans prepare eight tiles per CTA when the original block has 256 threads and the grouped grid retains at least four resident waves. The native 128-thread path remains selected for its existing scan. Single-request H1/H2 native recurrence uses four value slices and two MMA warps per CTA; this retains 16 state rows per warp and improves the underfilled grid without changing arithmetic or state precision. Every invocation reads the current device boundaries, including Graph replay. H12 preparation can use this grouping while its recurrence retains the original two-MMA/four-row-slice geometry. BF16 state pairs stay packed in 32-bit words, reducing the combined kernel's register footprint without changing its FP32 update or BF16 rounding.
